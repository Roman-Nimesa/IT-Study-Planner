# IT Study Planner

Веб-приложение для планирования учебных задач. Использует Firebase Authentication (регистрация и вход по email/паролю) и Cloud Firestore (облачное хранение задач).

## Файлы
- `index.html` — структура страницы.
- `style.css` — оформление и адаптация под мобильные устройства.
- `script.js` — логика приложения и подключение Firebase.
- `firestore.rules` — правила доступа к личным задачам.

## Запуск
Откройте папку проекта через локальный веб-сервер или опубликуйте её на GitHub Pages. Для ES-модулей Firebase не рекомендуется запускать страницу через `file://` двойным щелчком по HTML.

## Firebase
1. В Firebase Console включите Authentication → Sign-in method → Email/Password.
2. Создайте Cloud Firestore.
3. Вставьте содержимое `firestore.rules` во вкладку Rules и нажмите Publish.
4. Конфигурация веб-приложения находится в `script.js`.

Задачи сохраняются в `users/{uid}/tasks/{taskId}`. Правила разрешают доступ только авторизованному пользователю к документам внутри его UID.

## Проверка
- Зарегистрируйте аккаунт, войдите и добавьте задачу.
- Измените статус и удалите задачу.
- Перезагрузите страницу: данные должны загрузиться из Firestore.
- Войдите с другого устройства под тем же аккаунтом: задачи должны быть доступны.
- Создайте второй аккаунт: он не должен видеть задачи первого.
